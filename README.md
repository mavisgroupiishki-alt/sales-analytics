# Sales Analytics — v2

## Что изменилось

### 1. Убран anthropic SDK → прямые HTTP-запросы
Файл `claude_analyzer.py` теперь не зависит от `anthropic` Python-пакета.
Все запросы к Claude идут через `requests.post` напрямую на `https://api.anthropic.com/v1/messages`.

**Совместимо с Bitrix Vibe Code** — достаточно задать переменную окружения:
```
ANTHROPIC_API_KEY=sk-ant-...
```

Модель: `claude-sonnet-4-6` (вместо Haiku — для точности анализа).

---

### 2. Добавлены 11 типов звонков

Система теперь **сначала определяет тип звонка**, потом оценивает его по эталону именно для этого типа.

| Ключ | Тип |
|------|-----|
| `primary_incoming_new` | Первичный входящий (новый клиент) |
| `primary_incoming_existing` | Первичный входящий (действующий клиент) |
| `cold_new` | Первичный холодный (новый клиент) |
| `cold_periodika` | Первичный холодный (периодика, действующий клиент) |
| `cold_reactivation` | Первичный холодный (давно не было контакта, через пользу) |
| `kp_defense` | Защита КП |
| `kp_feedback` | Обратная связь по КП |
| `counteroffer` | Контроффер (особое предложение) |
| `objection_handling` | Отработка возражений |
| `payment_push` | Дожим клиента на оплату |
| `successful_payment` | Успешная оплата |
| `upsell` | Доп продажа (отдельный звонок) |

---

### 3. Эталонные сценарии для каждого типа

Каждый тип имеет:
- `stages` — список стадий, по которым должен идти менеджер
- `critical_stages` — обязательные стадии (пропуск = автотриггер)
- `success_criteria` — критерий успешного звонка

Пример для `payment_push`:
- Стадии: напоминание о договорённости → уточнение препятствий → снятие возражения → ограничение → конкретный вопрос о дате → фиксация даты
- Критические: "Уточнение — что мешает оплатить", "Фиксация точной даты/времени оплаты"

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
export ANTHROPIC_API_KEY=sk-ant-...
export BITRIX_WEBHOOK_URL=https://your-domain.bitrix24.ru/rest/1/xxxxx/

# Шаг 1: забрать звонки из Bitrix
python src/bitrix.py

# Шаг 2: анализировать
python src/claude_analyzer.py
```

## Переменные окружения

| Переменная | Обязательная | Описание |
|------------|-------------|----------|
| `ANTHROPIC_API_KEY` | ✅ | Ключ Claude API |
| `BITRIX_WEBHOOK_URL` | ✅ | Webhook Bitrix24 |
| `DOWNLOAD_AUDIO_COUNT` | ❌ | Кол-во аудио для скачивания (0 = не скачивать, -1 = все) |
